## 实际参考

使用 agent-reach 的 Exa 搜索和 Jina 网页读取找到 [Noita 官方 presskit](https://noitagame.com/press/)，实际查看了 [截图 005](https://noitagame.com/press/images/screenshot_005.jpg) 和 [截图 002](https://noitagame.com/press/images/screenshot_002.jpg)。浏览器控制工具启动失败后，用独立只读浏览器查看图片，未提取或导入 Noita 原贴图。

以下是对截图的视觉观察和本项目实现选择，不声称获取了 Noita 源码、精确色板或材质算法：

| 类别 | 参考中观察到的区别 | 本项目对应改动 |
| --- | --- | --- |
| 岩石 | 深冷色基底、细碎矿物集群、不规则疏密变化 | 离散冷灰色板、原生像素团簇、低频聚集分布；移除等距水平条带 |
| 泥土 / 湿土 | 黄褐色团块与细砂，区别于灰色岩体 | 独立暖土色板、团块与砂粒；湿土暗化，保留组织 |
| 木材 | 沿木梁或木纤维走向延伸的明暗纹理 | 独立方向性木纹、打断的暗缝和小断面；移动物体使用局部坐标纹理 |
| 接触边缘 | 小尺度颗粒和零碎植物，而非统一的发亮轮廓线 | 读取真实材料邻格，地表苔色断续进入 1–3 格；不在空处绘制假地面 |

## 代码边界

- 新增代码原生材质模块 `src/visual/forest-material-texture.ts`，接入实际地形和物件渲染。
- 不缩放概念图作为整片背景，不增加外部贴图库或绕过素材准入。
- 地形使用世界坐标，石木使用物体局部坐标；纹理不使用时间或相机坐标。
- 首轮实机检查发现哈希的坐标相关性造成网格伪影，补完整混合并复看。减少内部矿物密度，为暗色基底保留空间。
- 跨块采样使用四向邻格；缓存键同步纳入相同邻块，更新土水状态时局部刷新。
- 地图布局、实体占据格和 AABB 形状保持不变。物体外形仍不是 Noita 的任意多边形刚体；没有宣称完成形状、旋转或碎裂系统。
- 人物 v0.6、远景 v0.3、步态、镜头参数、任务、MP/学习门槛、存档 schema 均未修改。
