## 使用

- 唯一交付文件：`exports/windows/tokipona-rpg-latest.exe`，Windows x64 单文件便携包。
- 双击即可启动；游戏代码、运行时、人物 v0.6 和森林背景 v0.3 都在包内。不需要 Node、浏览器、校园网、Tailscale 或开发服务器。
- `F11`／`Alt+Enter` 切换全屏；移动、跳跃、互动、观察、笔记与浏览器版保持一致。
- 存档：`%APPDATA%/tokipona-rpg`，不会随 EXE 替换清除。临时重玩仍与主进度分开。
- 浏览器存档不会被自动读取或覆盖；首次开桌面版是独立进度。尚未实现跨浏览器／桌面导入合并，不冒称已迁移。
- 当前测试包未做发行代码签名。若 Windows 提示未知发布者，应核对文件来源；不关闭杀毒、SmartScreen 或系统安全策略。

## 安全与发布边界

桌面主进程仅提供 `tokipona://game/` 本地资源，限制路径与页面导航；不监听 HTTP 端口，不加载外网内容。渲染器禁用 Node 集成、启用沙箱与上下文隔离；不提供文件系统 IPC，不自动下载更新、不自动上传存档，不请求管理员权限。

本地包包含尚未正式获批的私人候选素材，因此 EXE 和截图均在 Git 忽略目录。它不等于公开素材审批、正式发行或 Android 验收。不要将 EXE 推到公开仓。

工程核对采用 agent-reach 的网页读取路径，依据 [Electron 本地协议](https://www.electronjs.org/docs/latest/api/protocol)、[官方安全指南](https://www.electronjs.org/docs/latest/tutorial/security) 与 [Windows 构建目标说明](https://www.electron.build/docs/win)。网站文档已包含 v27 改动，本项目实际使用 26.15.3 的安装包配置 schema 核对 portable 参数，不混用 v27 签名选项。
